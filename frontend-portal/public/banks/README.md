# Bank logo assets

The PNG files in this directory are the original bank brand marks returned by
the VietQR bank directory (`https://api.vietqr.io/v2/banks`) and served from
the corresponding VietQR CDN URLs. They were retrieved on 2026-09-28 and are
kept locally so the demo UI does not depend on a third-party image request.

All bank names and trademarks belong to their respective owners.
